# Explicação do desenvolvimento do site

## 1. Escolha do tema

Escolhi fazer um site sobre **corrida** porque é um tema que eu gosto bastante e gosto de correr. Também percebi que algumas pessoas têm dificuldade para começar porque não sabem por onde começar ou não encontram informações organizadas. Por isso, decidi criar um **site informativo sobre corrida**.

## 2. HTML

Comecei criando a estrutura do site usando **HTML**. Fiz o cabeçalho, menu, títulos, textos, imagens, botões e as diferentes seções.

## 3. Criação das páginas

Organizei o conteúdo em páginas diferentes:

- **Início:** apresentação do site.
- **Guia:** informações para quem está começando a correr.
- **Planilhas:** treinos organizados por semanas.
- **Dicas:** informações sobre aquecimento, hidratação e descanso.
- **Sobre:** explicação sobre a proposta do projeto.

## 4. Links

Conectei as páginas usando links no menu, para que o usuário consiga navegar pelo site e encontrar cada informação.

## 5. CSS

Depois usei **CSS** para cuidar da parte visual do site. Escolhi as cores, fontes, tamanhos, espaçamentos, imagens e botões.

Também utilizei **Flexbox** para organizar alguns elementos da página e deixar o conteúdo mais organizado.

## 6. JavaScript

Usei **JavaScript** para adicionar algumas interações ao site.

Essa foi uma das partes que tive mais dificuldade, porque no começo eu não entendia muito bem como fazer as funções funcionarem e como conectar o JavaScript com os elementos do HTML. Precisei pesquisar, testar várias vezes e corrigir alguns erros até conseguir fazer as ações funcionarem como eu queria.

## 7. Testes

Depois de terminar o site, fui testando as páginas, links, imagens, botões e as interações para verificar se tudo estava funcionando corretamente.

## 8. Publicação

Por fim, coloquei o projeto no **GitHub** e publiquei pelo **GitHub Pages**, deixando o site disponível para acesso pela internet.

## 9. Resultado

No final, consegui criar um **site informativo e organizado sobre corrida**, pensado principalmente para pessoas que estão começando e precisam encontrar informações de uma forma mais fácil.

# 🏃‍♀️ Blog de Corridas

## Sobre o projeto

Este é um site informativo sobre corrida, criado para ajudar pessoas que querem começar ou melhorar seus treinos.

## Objetivo

O objetivo é reunir informações sobre corrida de forma simples e organizada, facilitando o acesso a dicas e orientações.

## Páginas

- **Início:** apresentação do site.
- **Dicas:** dicas para melhorar a corrida.
- **Guia:** informações para corredores.
- **Planilhas:** sugestões de organização dos treinos.
- **Planos:** diferentes opções de treinamento.
- **Sobre:** informações sobre o projeto.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
